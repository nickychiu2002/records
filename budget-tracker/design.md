# 記帳本 App — 介面設計規劃

## 品牌定位
輕量、清晰、現代感的個人財務記帳工具，以 Google Sheet 作為後端資料儲存，讓使用者隨時掌握收支狀況。

## 色彩系統
| 用途 | 顏色 | 說明 |
|------|------|------|
| 主色 (Primary) | `#4F8EF7` | 藍色，代表信任與穩定 |
| 收入 (Income) | `#34C759` | 綠色，代表正向財務 |
| 支出 (Expense) | `#FF6B6B` | 紅橙色，代表花費 |
| 背景 | `#F8FAFF` / `#0F1117` | 淡藍白 / 深夜藍 |
| 卡片 | `#FFFFFF` / `#1C2130` | 純白 / 深藍灰 |

## 畫面清單

### 1. 首頁 (Home)
**主要內容：**
- 頂部：月份標題 + Google Sheet 連線狀態指示燈
- 收支總覽卡片：本月收入（綠色）、本月支出（紅色）、結餘（藍色）
- 記帳表單：
  - 日期選擇器
  - 收入/支出切換按鈕（Segmented Control）
  - 花費類別（依收入/支出動態切換）
  - 金額輸入
  - 備註輸入
  - 提交按鈕
- 圓環圖導覽區塊（三個方塊卡片）

### 2. 圓環圖展開視圖 (DonutChart Modal)
**主要內容：**
- 標題（本月支出 / 本季支出 / 本年支出）
- 動畫圓環圖（從 12 點鐘方向順時針繪製）
- 類別圖例（色塊 + 類別名稱 + 金額 + 百分比）

### 3. 設定頁 (Settings)
**主要內容：**
- Google Sheet 連線設定（Spreadsheet ID + API Key）
- 支出類別色彩自訂（色塊點擊 → 顏色選擇器）
- 收入類別管理

## 主要使用者流程

### 新增記帳
1. 開啟 App → 首頁
2. 填寫表單（日期 → 收入/支出 → 類別 → 金額 → 備註）
3. 點擊「新增」→ 資料寫入 Google Sheet → 更新總覽

### 查看支出分析
1. 首頁向下滾動 → 看到三個圓環圖卡片
2. 點擊「本月支出」→ 圓環圖動畫展開
3. 查看各類別佔比

### 自訂類別顏色
1. 進入設定頁
2. 點擊類別色塊 → 顏色選擇器
3. 選擇顏色 → 儲存

## 類別定義

### 支出類別
食物、交通、購物、娛樂、醫療、教育、住宿、其他

### 收入類別
薪資、獎金、投資、副業、其他
